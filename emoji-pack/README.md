# Emoji Pack

Turns common emoji shortcodes into Unicode emojis, for example:

- `:sob:` → 😭
- `:skull:` → 💀
- `:joy:` → 😂
- `:fire:` → 🔥
- `:pray:` → 🙏
- `:eyes:` → 👀
- `:heart:` → ❤️

## Important

A vanilla Minecraft resource pack cannot replace typed chat text such as `:sob:` by itself. The pack stores the shortcode mappings so a compatible chat/emoji mod can use them. A client-side mod is required for the actual `:sob:` → `😭` replacement.
